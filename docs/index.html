PAGIDA

παγίδα — Greek for "trap"

A phishing detector for Chrome that shows its working. Every page gets a risk score out of 100, and every point of that score traces back to a warning sign you can read for yourself.

Install from source Source on GitHub Read the evaluation

Verdicts you can argue with

Most phishing tools hand you a colour. Pagida hands you the reasoning, in the same words you would use to explain it to someone else.

Login form sends your password elsewhere  +32 The password box on this page submits to collector-node4.tk, not to verify-account.tk. That is how stolen credentials are collected.
Domain registered 3 days ago  +30 Almost all phishing sites run on brand-new domains. A week-old domain asking for a login is a serious warning.

You can disagree with it. You can learn from it. Both are worth more than a number.

Measured, not asserted

The repository ships an evaluation harness you can run yourself. It scores today's confirmed-phishing feed against 2,000 legitimate sites and 40 real brand login pages, using the same engine the extension runs.

Only the top band interrupts you, and it is set where address heuristics alone effectively cannot reach it — a warning that fires on one site in forty is a warning people learn to click through.

Nothing leaves your machine by default

Two optional lookups, both switchable off, neither carrying a page you visited.

  • rdap.org receives the domain name only — example.com, never the path or query string — to find out how old it is. Cached for a week.
  • raw.githubusercontent.com serves the OpenPhish public blocklist once every 12 hours. Matching then happens on your machine.
  • Google Safe Browsing is off by default, because it is the one lookup that would send full addresses to a third party. If you want it, you supply your own key.

No analytics, no account, no server, no sync, no telemetry. The extension does not request the tabs permission and cannot read your history.

Your judgement beats the score

Report a site as phishing and Pagida warns you about it from then on. Mark one as safe and it stops scoring it entirely. Right-click any link to check it without opening it.

Install

git clone https://github.com/AryanDhingraa/pagida.git
cd pagida
npm install
npm run build

Open chrome://extensions, turn on Developer mode, click Load unpacked, and select the dist folder. Chrome Web Store listing is in review.
